수행평가로 학생들에게 파이썬 데이터 분석 프로젝트를 내 주면 꼭 나오는 질문이 있습니다. "두 학생 코드가 거의 같은데, 베낀 걸까요?"

막상 비교해 보면 대부분은 베낀 게 아닙니다. 같은 교과서로 배우고, 같은 예제를 따라 쳐 봤으니 코드가 닮는 게 자연스럽습니다. 그래서 학습 사이트에 유사도 검사를 넣으면서 **"무엇이 같으면 의심할 만한가"**부터 다시 정했습니다.

## 1. 같아도 괜찮은 줄은 먼저 빼기

아래 같은 줄은 반 전체가 거의 똑같이 씁니다.

```python
import pandas as pd
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
```

그래서 비교하기 전에 세 가지를 지웁니다.

- **수업 자료에 나온 줄**: 학습자료·예제·문항에 있는 코드는 학생이 그대로 써도 정상입니다.
- **과제 안내문에 있는 줄**: 데이터 설명, 시작 코드 같은 것.
- **여러 학생이 같이 쓴 줄**: 네 명 이상이 똑같이 쓴 줄은 "흔한 줄"로 봅니다.

## 2. 두세 명만 같이 쓴 줄을 센다

흔한 줄을 다 지우고 나면 학생마다 **자기만의 줄**이 남습니다. 변수 이름, 그래프 제목, 고른 특성 같은 것들이죠. 그런데 이런 "드문 줄"이 **딱 두 학생에게서만** 여러 개 겹친다면, 그건 우연으로 보기 어렵습니다.

```python
# 드문 줄만 남긴 뒤, 둘만 같은 줄을 센다
rare_a = {ln for ln in lines_a if freq[ln] <= 3 and ln not in known}
rare_b = {ln for ln in lines_b if freq[ln] <= 3 and ln not in known}
shared = rare_a & rare_b
```

기준은 이렇게 잡았습니다.
- 둘만 같은 줄은 1점, 셋이 같은 줄은 0.5점
- 8점 이상이면서, 드문 줄이 적은 학생 기준 40% 넘게 겹치면 알림

짧은 줄(`plt.show()` 같은 것)은 처음부터 세지 않습니다.

## 3. 보고서 글은 20글자 조각으로

글은 문장 단위로 비교하면 조사 하나만 바꿔도 피해 갑니다. 그래서 공백을 지운 뒤 **20글자씩 겹치게 잘라** 비교했습니다. 여기서도 과제 안내·데이터 설명에 있는 조각은 미리 뺍니다.

## 4. 처음 돌려 본 결과

예상과 달리 **알림은 0건**이었습니다. 미리 살펴봤을 때 겹치던 코드는 대부분 교과서 예제를 충실히 따라 친 것이었습니다. 시험 삼아 한 학생의 코드를 다른 학생에게 그대로 복사한 가짜 데이터를 넣어 보니, 그때는 바로 잡혔습니다.

## 5. 판정은 사람이

이 검사는 "같다"까지만 알려 줍니다. 같이 공부하다 비슷해졌는지, 한 명이 대신 해 줬는지는 학생과 이야기해 봐야 압니다. 그래서 점수는 **의심 정도**로만 보여 주고, 정상·확인 필요·면담 중 하나는 교사가 고르게 했습니다.

교과서를 열심히 따라 한 학생이 억울하게 의심받지 않는 것, 그게 이번에 가장 신경 쓴 부분입니다.
